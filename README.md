# SpendSmart — Smart Budget Monitor

## Overview

SpendSmart is a personal finance management application developed using Thunkable as part of the **Computer Science for Data Scientists** module at the Lucerne University of Applied Sciences and Arts (HSLU).

The application is designed to help users monitor a monthly budget, track spending, review individual transactions, and explore expenses by category.

## Features

### 1. Monthly Budget Management

* Enter and save a monthly budget.
* Display the current budget amount.
* Monitor how much of the budget remains available.

### 2. Spending Overview

* Display total spending.
* Calculate the remaining budget.
* Show the percentage of the budget used.
* Visualize budget usage with a progress slider.

### 3. Transaction Overview

* Browse transactions and their associated categories.
* View categories such as Food & Drink, Utilities, Rent, and Shopping.
* Select individual transactions to view additional details.

### 4. Transaction Details

The transaction details screen displays information such as:

* Transaction date
* Transaction description
* Category
* Transaction amount

### 5. Currency Options

The interface includes currency options such as CHF, EUR, USD, and GBP, alongside fields for converted budget and spending values.

### 6. Category Filtering

* Select a transaction category.
* Apply a category filter.
* Display the number of matching transactions.

## Tools and Technologies

* **Thunkable** — visual mobile application development platform
* **Visual programming** — application logic and user interface interactions

## Project Context

Developed as part of the Computer Science for Data Scientists module at HSLU.
