# SpendSmart — Personal Finance Management App

## Overview

SpendSmart is a mobile application developed using Thunkable as part of the Computer Science for Data Scientists module at the Lucerne University of Applied Sciences and Arts (HSLU).

The project explores how a mobile application can support personal finance management and help users become more aware of their spending habits.

## Objectives

* Explore the design and development of a mobile application.
* Apply programming logic through Thunkable's visual development environment.
* Create a user-oriented solution for personal finance management.

## Tools and Technologies

* **Thunkable** — visual mobile application development
* **Visual programming** — application logic and component interactions

## Project Context

Developed as part of the Computer Science for Data Scientists module at HSLU.
